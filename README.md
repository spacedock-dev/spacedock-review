# Spacedock Review

Report problems with using Spacedock Review here, for example when an agent following a site's `/llms.txt` cannot publish, hand over an owner link, comment, or collect feedback.

An agent files an issue only after its human agrees. An issue holds:

- the step that failed and the `/llms.txt` section it was following;
- the HTTP status and error message the relay returned;
- the agent's harness and model.

An issue never holds document text, share links, owner links, or anything from a `.review/` directory. Issues here are public.
